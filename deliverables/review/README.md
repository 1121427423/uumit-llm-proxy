# 独立评审子代理（review/）

## 它是谁

`review_agent.py` 是一个**独立于构建流程的评分子代理**：不参与渲染、不信任构建脚本的自我宣称，
只把成片 mp4 当成一个黑盒来现场测量，输出 100 分制评分卡，并设 **80 分及格线**。

> 用户要求：**分数 < 80 时必须给出优化建议并重新生成视频**。本目录保留了全部轮次的评分卡，
> 可以逐条对照「失分点 → 返工动作 → 复测分数」。

## 评分维度（满分 100）

| 维度 | 满分 | 现场测量的指标 |
|---|---|---|
| 技术规格与兼容性 | 15 | 容器/编码档位/像素格式/faststart/音轨规格、时长与帧数精确性 |
| 节奏与音画同步 | 25 | 每个切点的低频强调系数、0.5 s 拍网格对齐的非巧合性、实测 BPM、镜头时长层次 |
| 运动与流畅度 | 15 | 冻帧数、镜头内最小帧间差、镜头内最大/中位帧间差比（已排除跨切点帧） |
| 画面质量 | 20 | 拉普拉斯方差（清晰度）、死黑/过曝比例、帧间噪声、相邻镜头直方图距离 |
| 剪辑结构与叙事 | 15 | 首尾淡入淡出、运镜方式与素材源数量、中段高光闪烁的强度与时机 |
| 合规与可复现 | 10 | 许可标注、脚本齐备、完整文档、工具链固化 |

## 用法

```bash
cd deliverables
python3 review/review_agent.py --variant landscape   # → review/scorecard-landscape.{json,md}
python3 review/review_agent.py --variant portrait    # → review/scorecard-portrait.{json,md}
echo $?      # 0 = 通过（≥80）；1 = 未达标（评分卡末尾会给出按失分排序的返工建议）
```

评分卡里每条指标都带**实测数值**；凡未拿满分的指标，末尾的「优化建议（按失分权重排序）」
都会给出对应的滤镜/参数级返工动作（对照表见 `review_agent.py` 里的 `SUGGESTIONS`）。

## 轮次记录

| 轮次 | 成片 | 总分 | 结论 | 评分卡 |
|---|---|---|---|---|
| 第 1 轮 | v1 横版（10×2.0 s 等长切分） | **79.7** | 未达标 → 触发返工 | `scorecard-landscape-round1.{md,json}` |
| 第 2 轮 | v2 横版（0.5 s 拍点、长短镜对比、淡入淡出、抬暗部） | **92.9** | ✅ 通过 | `scorecard-landscape-v2.{md,json}` |
| 第 2 轮 | v2 竖版 9:16（同一音乐床与切点） | **96.8** | ✅ 通过（历史值，已被第 3 轮覆盖） | — |
| **第 3 轮** | **v3 横版 / 竖版（降重复：镜像 / 倒放 / 局部特写 / 多取景窗 / 冷暖交替）** | **97.3 / 97.4** | ✅ 通过（**重复度 0.0**） | `scorecard-landscape.{md,json}` / `scorecard-portrait.{md,json}` |

第 3 轮的触发原因是**观众反馈「画面重复度太高」**——它不是评分卡里的失分项，因此另做了
`tools/repetition_audit.py`（任意两镜头撞脸检测，报告见 `../reports/rep-*.{md,json}`）。
三轮迭代：v3 六种手法全开（8.9 → 2.2）→ v3.1 B 素材改局部特写 → v3.2 第 7 镜加倒放+横扫，
最终 **重复度 0.0 / 100、高度重复对 0 对**，评审总分 92.9 → **97.3（横版）/ 97.4（竖版）**。
详见 `../DOCUMENTATION.md` §5.1 / §5.1a / §5.5 / §8.4。

第 2 轮剩余失分（均为「已达标后的可选打磨」，评分卡会自动列出并给出动作）：
横版暗部再抬一档（死黑 22.6%，<20% 即满分）、近似静态镜头加更明显的推拉（最小帧间差 1.29 < 1.5 满分行）、
素材源数量（本环境夜景素材上限 3 支）、切点低频强调均值（2.28× vs 满分线 2.6×）。

第 1 轮的主要失分点与对应返工（详见 `../DOCUMENTATION.md` §8.2）：

1. **镜头时长层次 0.5/4** — 10 支镜头全是 2.000 s，等长切分没有张弛 →
   切点重排为 0.5 s 拍点的整数倍：`3.0/2.0/1.5/1.0/2.5/1.0/1.5/2.0/2.0/3.5`。
2. **开场/收尾 0/5** — 无淡入淡出 → `fade in 0.35 s` + `fade out 0.55 s`。
3. **死黑像素 29.1%** — 暗部被压到 0 → `colorlevels=rimin/gimin/bimin=0.035` + `eq=gamma=1.04`。
4. **合规 5/10** — 缺完整文档与工具链 → 落盘 `DOCUMENTATION.md` 与 `tools/`（含安装包与 sha256 锁）。
5. **「镜头内无异常跳变」度量 bug** — 旧实现 `d[k*60:(k+1)*60]` 把**跨切点的那一帧差分**算进了镜头内最大跳变，
   产生 60.1 的假尖峰；已改为按真实切点切片 `d[fcuts[k]:fcuts[k+1]-1]`。

> 说明：第 1 轮的 79.7 分是「v1 成片 + 旧版评分器」的结果；把评分器修好、文档与工具链补齐后，
> 同一支 v1 成片再测会得到 86.8 分。但**成片本身的两个真实短板（等长切分、无淡入淡出、暗部死黑）
> 依然存在**，因此按用户要求对成片也做了返工重渲，而不是只修评分器。
